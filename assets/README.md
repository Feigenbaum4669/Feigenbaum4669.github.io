# Profile image

The home page currently uses `profile.svg` — a stylised placeholder.

When you want to use a real photo, drop a square JPG/PNG here as `profile.jpg`
(or `profile.png`) and update the `image:` line in `../index.qmd` to point at it.
Quarto handles the rest.

Recommended: square image, ~600×600 px or larger.

## Why an SVG and not the meme image directly?

The GigaChad meme is based on a copyrighted photograph by photographer
Krista Sudmalis (subject: Ernest Khalimov). Redistributing the original
photo from your repo isn't a great idea even as a placeholder. The SVG
here is an abstract silhouette that nods at the joke without copying
anyone's image, and it makes the "this is a placeholder" status obvious.
